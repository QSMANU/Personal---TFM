# Revisiones persistentes

Guarda aquí las revisiones académicas extensas que deban conservarse íntegramente y compartirse entre asistentes. Usa nombres como `2026-09-28-seccion-2-1-contexto-problema.md`.

Cada revisión debe indicar:

- autor o asistente que la produjo;
- fecha y versión del texto revisado;
- problemas detectados;
- cambios sugeridos;
- citas o fuentes pendientes;
- figuras propuestas;
- decisiones que requieren validación del director.

Además del archivo, crea una nota breve en `context-mcp` que resuma el resultado y apunte a esta ruta.
