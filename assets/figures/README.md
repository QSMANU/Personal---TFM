# Figuras e imágenes

Cada figura debe conservar, como mínimo:

- archivo original o editable;
- fuente original y autor u organización;
- URL o DOI estable;
- licencia o condiciones de reutilización;
- fecha de acceso;
- pie de figura propuesto;
- sección del TFM donde podría utilizarse.

No reutilices una imagen únicamente porque aparezca en un buscador. Cuando sea posible, crea figuras propias a partir de datos correctamente citados.
