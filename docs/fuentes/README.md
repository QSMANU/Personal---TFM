# Fuentes académicas

Guarda aquí únicamente artículos, informes o datasets que puedan almacenarse legalmente. Para cada fuente registra en `../INDEX.md` su referencia bibliográfica, DOI o URL estable, fecha de acceso, páginas relevantes y afirmaciones que puede respaldar.

Si una licencia no permite conservar el archivo, registra solo la referencia y un resumen propio.
