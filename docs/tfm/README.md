# Documentos propios del TFM

Organización recomendada:

- `propuesta/`: formulario, presentación y alcance inicial.
- `memoria/`: documento editable principal y materiales de trabajo.
- `entregas/`: copias inalteradas de cada entrega oficial, separadas por fecha o número.

Git conserva el historial, por lo que no hace falta crear copias numeradas de cada pequeña edición. Reserva las versiones fechadas para entregas o hitos reales.
