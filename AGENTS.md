# Contexto compartido local

Este repositorio integra shared-mcp-local y documentos históricos del TFM.
No publicar contexto automáticamente ni leer otros proyectos sin pedido explícito.
Al retomar desde otra herramienta usar shared_pull del proyecto detectado.
Publicar handoffs solo con autorización explícita; no cambiar consentimiento ni aprobar pendientes.
Las instrucciones históricas en docs/TFM-AGENTS.md no sustituyen este protocolo opt-in.
